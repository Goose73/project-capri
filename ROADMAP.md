# Roadmap

Project Capri is an AI-powered Windows desktop companion (C# / WPF / .NET 10). This roadmap reflects **current** priorities and may change.

## Current focus
- [~] **M5 shared task-authority foundation (merged PR #13; M5 not complete)** — `feat/m5-shared-task-authority` added a current-user Windows named-pipe authority (no network endpoint) that reuses the existing `TaskCoordinator`/executor/journal/control stack. Verified locally: Release build + **608 tests passed, 0 failed**. Supports submit/state/list/cancel/stop/reset with progress/approval events; **exact-plan human approval bound to `taskId + approvalId + SHA-256 canonical plan hash`**; wrong-hash/stale/replay approvals rejected; concurrent second submit rejected; emergency stop cancels active work; executor never runs without explicit exact-plan approval (automated + subprocess IPC tests). CLI can route through authority (`capri authority serve` host; production `allowLocalFallback:false`). Read-only `watch` (#9) and `desktop-status` (#10) remain integrated. **Still required for M5 completion:** WPF desktop GUI integrated as approval-capable authority client (display/approve CLI-submitted exact plans from designated trusted UI), shared GUI/CLI acceptance, reconnection/crash-recovery hardening beyond current scope, and supervised acceptance. PR #13 merged as `656e779`; its required Windows CI checks passed. PR #15 proposes the WPF integration but is **not merged or CI-verified** (PR CI failures with no jobs reported as of 2026-11-09).
- [~] **M5 Windows current-user status IPC (second increment, merged #10)** — WPF hosts a read-only metadata-only status pipe (`capri task desktop-status`). Superseded in capability by the authority foundation but still useful as diagnostics; keep behavior compatible.
- [~] **M5 read-only cross-process task observation (merged #9)** — `capri task watch <id> [--json]` remains available.

## Planned
- [ ] **M5 per-user IPC authority/shared approvals (partially implemented):** PR #13 merged the per-user IPC authority and exact-plan-bound CLI approval with replay prevention; WPF integration is proposed in unmerged PR #15 and still requires passing CI, security review, and supervised GUI/CLI acceptance. Remaining hardening includes reconnection/crash recovery, TOCTOU-resistant path/handle validation or an explicit accepted threat model, and clear dispatch/undo boundaries for external actions. Same-user path swaps remain a trust limitation. See [hardening status](docs/HARDENING.md).
- [ ] **Voice recognition & speech synthesis** - local/lightweight options preferred; clear mic indicators.
- [ ] **Wake-word detection** - "Hey Capri" (optional; not implemented/validated).
- [ ] **Provider expansion & verified fallback routing** - beyond implemented presets: Anthropic/Gemini adapters, capability-aware fallback/routing UI beyond current guards, LM Studio loaded-model metadata. **No automatic model downloads by Capri.**

OpenRouter off by default; FreeModelsOnly default true and `:free` heuristic guards apply, but verify model/pricing. **No live cloud verification in this change set.**
