# Roadmap

Project Capri is an AI-powered Windows desktop companion (C# / WPF / .NET 10). This roadmap reflects **current** priorities and may change.

## Current focus
- [x] **Free/local AI live validation (M3 verified, 2026-11-08)** - M1-M6 catalog implemented. Real local proof (Ollama v0.40.9, no API key): approved `ollama pull qwen3:4b-instruct` completed (~2.5 GB, SHA verified). Installed: `qwen3.5:4b`, `qwen3:4b-instruct`.
  CLI verified (exit 0): `capri models list`, `models recommend`, `models use qwen3:4b-instruct` (persisted), `providers test` (actual inference, 1465 ms warm; probe text not matched exactly), `capri ask "What is Project Capri?"` (genuine local response). `capri chat` correctly refuses non-interactive stdin. Fix: CLI model-management targets local Ollama when active provider is not Ollama. **Latest (after setup fixes): 585/585 tests pass (Release, 0 failed, exit 0), Release build 0 warnings, 0 errors, Gitleaks clean on staged M4 publication candidates.** Previous independent QA: 577 + 2 separate process tests. Setup safeguards recorded (diagnostics-only/no saves, guarded provisional saves, exact tag matching); reduced motion persisted; Release launcher and CI smoke recorded.
- [x] **CLI Milestone 1 + M3 (partial, verified core path)** - `capri start/ask/chat/status/providers test/models list|recommend|use|pull`. Pending manual acceptance: interactive TTY `capri chat` multi-turn, streaming UX, Ctrl+C in-session generation cancellation (Windows Terminal). `providers test`/cold local inference may need timeout tuning (300s used locally vs 60s default).
- [~] **M4 terminal autonomy (implemented, partially verified; live supervised acceptance pending)** - `capri task "<request>"` uses the existing `TaskCoordinator`/`TaskPlanParser`/`SafeTaskExecutor`/journal with real configured provider planning (no separate autonomous engine). Adds `capri tasks`, `capri task status <id>`, `capri task stop`, `capri task reset-stop`, `capri task history`, help/dashboard updates, and terminal approval UI. Safety: exact plan shown before execution; explicit interactive approval (`approve PLAN` intent as implemented) defaults to rejection for non-interactive/EOF/timeout/cancelled input; piped/non-interactive `capri task` refuses exit 2 with no dispatch (verified). Workspace selection required for note plans; safe note names/no-overwrite; no untrusted model output executed directly; allowlist/parser bounds preserved. Cross-process file-based metadata-only control/history (`tasks/`, atomic bounded JSON, no secrets/prompts/plan/targets/note text): single-active-task ownership, shared stop latch/reset generation, metadata status/history; `TaskCoordinator` honors shared stop and desktop is wired. **Limitation:** stop is effective at checkpoints/queued work and cannot forcibly interrupt an in-flight blocking operation or undo already-dispatched external actions. `capri task stop --json` / `reset-stop --json` verified. **Live supervised acceptance NOT completed by the agent** (real local-model Ollama plan + explicit user approval + disposable workspace note create/verify + Notepad open + window observation); manual supervised steps required.

## Planned
- [ ] **M5 per-user IPC authority/shared approvals (future, not done):** cooperative single-owner foundation remains; no full M4/M5 security isolation. Future secure per-user IPC milestones: real per-user IPC/task authority with authenticated caller identity; shared authoritative approval state across CLI/WPF bound to the exact plan/request; **no replay** of task actions from metadata/control state; TOCTOU-resistant path/handle validation or explicit accepted threat model; clear dispatch/undo boundaries for external actions. Same-user path swaps remain a trust limitation. See [hardening status](docs/HARDENING.md).
- [ ] **Voice recognition & speech synthesis** - local/lightweight options preferred; clear mic indicators.
- [ ] **Wake-word detection** - "Hey Capri" (optional; not implemented/validated).
- [ ] **Provider expansion & verified fallback routing** - beyond implemented presets: Anthropic/Gemini adapters, capability-aware fallback/routing UI beyond current guards, LM Studio loaded-model metadata. **No automatic model downloads by Capri.**
- [ ] **Cloud provider live validation (explicit consent; avoid surprise charges)** - OpenRouter/OpenAI require keys and can incur charges. OpenRouter off by default; FreeModelsOnly default true and `:free` heuristic guards apply, but verify model/pricing. **No live cloud verification in this change set.**
- [ ] **Desktop release packaging & installer** (not built).
